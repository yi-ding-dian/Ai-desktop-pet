# 记忆提取（后台任务专用提示词）

你在后台为一只桌面宠物整理它和用户对话的长期记忆。请阅读下面的对话记录，
提炼**关于用户**、值得长期记住的信息。

## 输出要求

只输出一个 JSON 对象（不要解释文字、不要 markdown 代码块）：

```
{
  "memories": [
    {"text": "用户叫张三，是一名中学教师", "kind": "fact", "importance": 0.9},
    {"text": "用户喜欢喝拿铁咖啡", "kind": "preference", "importance": 0.6}
  ],
  "profile": [
    {"key": "称呼", "value": "张三"},
    {"key": "职业", "value": "中学教师"}
  ]
}
```

## 规则

- memories：只提取**长期有效、关于用户**的信息；宠物自己说过的话、寒暄、
  一次性的闲聊（如"今天天气不错"）都不要提取。
  - kind 取值：`fact`（客观事实：姓名、职业、居住地）/
    `preference`（喜好、习惯、忌口）/
    `event`（用户的经历或约定：如"下周要出差"）
  - importance：0~1 的小数，越重要越接近 1（姓名/称呼 0.9；一般喜好 0.5~0.7；
    次要信息 0.2~0.4）
  - text 写成一句自然、自包含的话（不要出现"他说""用户刚才提到"等上下文依赖）
- profile：结构化画像条目（key 用简短中文：称呼/姓名/性别/城市/职业/爱好……），
  有明确信息才写；没有就输出空数组 `[]`。
- 数量克制：memories 最多 8 条，宁缺毋滥；不确定的信息不要写入。
- **记忆本内容不要重复提取**：用户明确说“记住/收藏/存到记忆本”的链接、本机路径、
  编号、短文本，由「记忆本」精确保存；不要把链接 URL、文件路径这类内容写进 memories
  （自然语言记忆会改写/截断它们）。只提取关于用户的长期事实、偏好与约定。
- 用户已经明确删掉/忘掉的记忆本内容，不要从对话记录里重新提取。
- 对话记录里没有可提炼内容时，输出 `{"memories": [], "profile": []}`。
