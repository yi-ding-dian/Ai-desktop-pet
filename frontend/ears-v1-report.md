## 3. 耳朵几何标定（数值怎么来的）

离线遍历 GLB 顶点（应用节点旋转 + 居中/贴地后 28,749 顶点；`/tmp/pet-ears/` 下的
`analyze_ears.py` / `slice_ears.py` / `classify_ears.py`）：

1. **y 切片聚类**（步进 0.01、x 间隙 0.035）找到"头壳 → 两耳"分裂点：y≈0.79 处由 1 簇变
   2 簇 → **耳根高度 ≈ 0.79**；
2. 实测耳轴（root 局部，脚底原点）：
   - **左耳**（观察者左，外张幅度大）：根 (-0.125, 0.785, -0.085) → 尖 (-0.350, 0.955, -0.135)，
     轴长 0.286，外张 54°；
   - **右耳**（近竖直、向后弯）：根 (+0.095, 0.785, -0.040) → 尖 (-0.020, 1.070, -0.265)，
     轴长 0.381；两耳是不对称造型；
3. **判定规则** = 胶囊包络：顶点沿耳轴投影 s ∈ [-0.02, 轴长+0.03] 且到耳轴垂距 < 判定半径
   （L 0.130 / R 0.115）→ 命中 **L 2,246 顶点 / R 2,485 顶点，两耳重叠仅 11 个**；
4. **染色实验复核**（见 §5 图）：点云覆盖双耳无遗漏、头壳/脸无误伤；头壳"误伤"仅限耳根
   下方 0.02 轴向内的过渡环，角度分布规定该处恒 0，不产生任何可见变形。

## 4. 实现结构与调参（想改什么改哪）

```
ears/
  config.ts   ← 全部可调参数都在这里
  overlay.ts  ← 实现（一般不需要动）
```

**形变原理**：顶点级**分布式角度旋转**——每个顶点绕"铰链轴"转的角度 = 目标角度 ×
分布系数 g(t)（t = 沿耳位置 0→1；耳根 0 → 耳尖满角，smoothstep 平滑）。旋转在 mesh 本地
空间执行，铰链轴由 root 空间的标定一次性换算（该 GLB 的 mesh 本地空间带节点 +90° 旋转，
直接绕世界轴转会转错方向——这是实现时踩过的关键坑）。

**铰链轴**（config 不需直接管，改 `EarSpec.fall` 才影响）：
- 倒下轴 = 耳轴 × "垂下方向"（fall，外下 45°）→ `roll` 正 = 耳尖朝外下轻倒，
  负 = 向内上轻立（两耳语义一致、符号自动统一）；
- 俯仰轴 = 垂直于前两者 → `pitch` 正 = 耳尖向前，负 = 向后。

| 参数组（config.ts） | 作用 | 调整示例 |
| --- | --- | --- |
| `EMOTION_EAR_POSES` / `STATE_EAR_POSES` | **情绪/状态耳态表**：每耳 `roll`（微倒角，度）/`pitch`（微俯仰，度）/`curl`（微卷曲，弧度） | "sad 再垂一点"→ `sad.L/R.roll` 5/6 → 7/8；**请克制在 ±15° 内** |
| `EAR_SWAY` | 常驻轻晃：幅度（弧度）+ 频率（Hz） | "晃得再含蓄些"→ `amp` 0.035→0.02 |
| `EAR_TWITCH` | 随机耳抖：间隔 5–10s、峰值 0.075 rad（~4.3°）、时长 0.5s | "抖勤一点"→ `gapMin/gapMax` |
| `EAR_HAPPY_SWAY` / `EAR_SLEEP_SWAY` | happy 轻快摆动（~2.9°@1.3Hz，两耳反相）/ sleepy·sleeping 极缓呼吸摆（~1.1°@0.2Hz） | — |
| `EAR_INTENSITY.low` | 强度 0 时保留的角度比例（0.55，与姿态层同思路） | — |
| `TAU_EAR` | 耳态过渡时间常数（0.4s，缓慢飘过去） | "切换再缓一点"→ 0.55 |
| `EAR_L / EAR_R` | **几何标定**（根/尖/半径/fall）：换模型才需要动 | 方法见 §3 |
| `EAR_WEIGHT` | 角度分布（耳根固定环 5%、中段渐增）：微动量级下不敏感，为将来留调节位 | — |

**性能**：仅"姿态变化时"才重写耳朵顶点（姿态签名比对，静止则跳过）；微动常驻 →
实际大部分帧都在更新，但成本约 0.1–0.3ms/帧（4,700 顶点 × 两次轴角旋转，直接操作
交错缓冲的底层数组），60fps 实测无回退（§5.4）。法线不重算（微动幅度下误差远低于可见阈值）。

## 7. 坑与遗留

- **大角度形变的"接缝拉伸窗"（重要教训，已留档）**：本项目先做过"大幅垂耳"（sad 两耳
  60°–140°）版本。实测结论：耳朵与头壳是**一体网格**，判定边界的"硬边"在**大角度旋转**
  下（>15°）会在耳根内侧出现"顶点位移不连续"→ 接缝处面片被拉长/翻转，裸眼可见"破洞/
  折痕"（截图留档：`diag2-sad-front.png`、`diag-sad-cull.png`）。修复尝试（分布式旋转
  替代权重混合、根部固定环、小 roll 大 curl 分摊）能把"可用幅度"推到 ~120°，但仍存在
  "耳根固定桩"与"中段折痕"的观感代价；**最终的"微动"方案（≤9°）则在物理上完全无痕**
  ——这正是本方案收敛边界的由来。若将来要做"真垂耳"，正确路线是**骨骼版模型**
  （Meshy Smart-Rig，见 `index.ts` 头部"待骨骼版的接入点"），而不是继续加码顶点形变。
- **法线不更新**（权衡）：微动幅度下（每顶点 ≤9°、位移 ≤ 数毫米）光照误差不可见；
  如做大幅形变需改"低频重算法线"。
- **HMR 与实例**：本项目对"渲染器实例字段"热更新路径复杂——本次用"30° 可见实验"确认了
  config 常量改动（整页 reload 路径）可实时生效；但**任何后续"看起来没反应"都请先做
  可见实验再下结论**（不要假设）。
- **性能备注**：微动常驻 → 变化检测几乎每帧都判定"有变化"（这是设计使然：耳朵一直在
  轻轻动）；"静止帧零计算"在"耳朵完全静止"时才触发（例如微摆恰好过零 + 无耳抖的瞬间）。
  成本已实测无压力。
- **遗留**：① 耳朵不做"摸头反应/转头的独立联动"（随头壳整体运动是免费的）；② 无"随机
  per-情绪微变化"（连续看可能略显周期性——当前用"轻晃 + 随机耳抖"双轨缓解）；
  ③ 双耳共用一套微行为相位（刻意为之：两耳同频轻晃更像"呼吸"；如要"各自晃"把
  `updateMicro` 的相位拆两路即可）。
