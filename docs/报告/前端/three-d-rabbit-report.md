## ① 渲染风格：soft 3D 毛绒感（`style: 'fluffy'`）

| 维度 | v2（卡通描边） | v3（毛绒重做） |
|---|---|---|
| 材质 | MeshToonMaterial 分带 | **MeshPhysicalMaterial + sheen/sheenColor**（绒毛边缘光——three 内置最接近绒毛的手段）+ 高 roughness（0.92）+ 无金属无塑料高光 |
| 描边 | inverted-hull 深色描边 | **无描边**；改为**浅色绒毛壳**（同几何背面、暖白半透明、世界厚度均匀外扩 = 轮廓毛绒光晕） |
| 光照 | 卡通平光（高对比分带） | **大面积柔和漫射**：Ambient 2.1 + 半球 1.2 + 温柔主光 0.5 + 补光 0.25（低对比、无硬阴影；按 three 的 1/π 因子配平） |
| 白 | 纯白 #FFFFFF（卡通平涂） | **奶油白 #F7F4EE**（暖白毛绒） |

**"双层绒毛壳"评估结论（诚实）**：程序化几何无毛发纹理，放大壳层只会"糊化五官边缘"、收益低且有穿帮风险，
未采用；sheen + 浅色绒毛壳已给出"柔和绒光的软萌 3D"。
**但"每根毛"的真实皮草质感程序化达不到**——若最终对毛绒度不满意，出路是引入真实 3D 毛绒模型（glTF/VRM 建模资源）。

## ③ 拟人化走路（walkStyle = 'human'，弃用蹦跳）

- **双腿交替迈步**：髋部轴心旋转（左右反相 ±0.62 rad）+ **前摆时抬脚**（离地抬升，短腿在遮挡下也读得出）
- **双臂反向轻摆**（与对侧腿同相，自然摆臂）；**身体随步起伏**（每步一次下沉）+ **侧倾**（重心转移 ±2.2°）+ **微前倾**；
  **头部稳定微点**（2× 步频小点头）；**耳朵随步态延迟晃动**（相位滞后）
- **节奏与窗口移动速度匹配（零接口改动）**：渲染器外壳每帧读 `window.screenX/screenY` 差分求出**窗口实际移动速度**（指数平滑），
  喂给 animator：`步频 = 速度 / 步幅（90px）`，clamp [0.9, 3.2] 步/秒——
  walk 行为按 distance/duration_ms 缓动移动窗口（默认速度 ≈ 140px/s → 约 1.55 步/秒，自然步频）；缓动两端步频自然变慢
- **idle**：站立微呼吸 + 双手合十 + 偶尔歪头/耳抖；sleeping/thinking/speaking/dragging 沿用（姿态按站姿适配）
- 8 情绪耳朵系统**保留**（竖耳/垂耳/后压/猛竖/内折/一竖一斜），眼形/嘴/腮红协同继续有效

## ⑤ 坑与遗留（诚实列，含"我还认为差的点"）

**本轮坑**
1. **马甲与矮胖梨形身体的几何冲突**：环状球带（同心于身体）在"下宽上窄"身上必然被顶穿 → 改为**与臀球同心的球带**（外扩 6%）解决。
2. **头大打脸遮马甲**：头底过低时马甲肩部全被头挡（只剩围脖感）→ 抬高头（下巴压在胸上）。
3. **脸颊"两个粉球"感**：颊球过外加腮红叠在球上 → 颊球内收加大、与头球融合成连续宽脸。
4. **卧蚕曾跑到"嘴角侧"像獠牙**：卧蚕 z 前凸 + 眼位变化 → 贴脸（z 0.022）+ 回眼下缘。
5. **toon 的教训延续**：three 漫反射 1/π 因子——fluffy 光强按 π 配平一次到位（未再复现发灰）。

**还差的点（我自认为）**
- **毛绒度**：sheen 是"光感的绒"，不是"毛的绒"；近观没有毛丝细节（程序化上限，见 ① 说明）。
- **手形**：原型是"合掌有手指"，我们是"两只圆掌靠拢"；手指分叉未做。
- **脸的下半过渡**：颊球与头球的融合区在侧 45° 视角可能看出"两球交叠"的浅痕（正面无碍）。
- **腿部**：短腿大部分被身体下缘遮挡（原型蹲坐本来如此）；走路时腿的可见度有限（靠"抬脚"补偿）。
- **走路节奏**：离线预览无窗口移动 → 走下限 0.9 步/秒；真机上的"速度匹配"需要实际走一段路验证主观手感（建议用户按 W 键触发走路观察）。
- **马甲 V 领**：用白色贴片表达（非真实挖口）；极侧视角略有贴片感。
- 单段耳下"耳尖折"仍为整耳近似（v2 说明沿用）。
